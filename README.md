# protocol-design.github.io

Website of the CHI 2027 meet-up **Meeting Protocol Designers at CHI: Towards Distributed Autonomous Futures**
(Pittsburgh, PA, USA, May 2027). Served by GitHub Pages at <https://protocol-design.github.io>.

## Files

| Path | Content |
|---|---|
| `index.html` | Meet-up page: guiding questions, audience, schedule, accessibility, organizers, reading list, citation |
| `materials.html` | Large-print, screen-readable prompts, provocation cards, badge colors, and wall-map description (promised in the paper) |
| `assets/style.css` | Shared styles; no build step, no JavaScript |
| `.nojekyll` | Serves files as-is (skips Jekyll) |

## Editing

Plain HTML and CSS. Edit, commit, and push to `main`; GitHub Pages republishes within a minute or two.
